# 11. Variáveis Bash

Este README secundário reúne notas de consulta e encaminha para documentação mais detalhada. Os links internos usam caminhos relativos e funcionam no GitHub e em editores Markdown.

## Itens desta tabela

### 1. `declare [variable]=[value]`

- Expansão/origem: —
- Descrição: Declarar uma variável Bash
- Em inglês: Declare a Bash variable
- Ajuda local: consulte `man comando` ou `comando --help` quando disponível.

### 2. `echo $[variable]`

- Expansão/origem: —
- Descrição: Exibir valor da variável
- Em inglês: Display value of the variable
- Ajuda local: consulte `man comando` ou `comando --help` quando disponível.

### 3. `export [variable]`

- Expansão/origem: —
- Descrição: Exportar uma variável Bash
- Em inglês: Export a Bash variable
- Ajuda local: consulte `man comando` ou `comando --help` quando disponível.

### 4. `let [variable]=[value]`

- Expansão/origem: —
- Descrição: Atribuir valor inteiro à variável
- Em inglês: Assign integer value to var
- Ajuda local: consulte `man comando` ou `comando --help` quando disponível.

### 5. `set`

- Expansão/origem: —
- Descrição: Listar variáveis e funções
- Em inglês: List variables and functions
- Ajuda local: consulte `man comando` ou `comando --help` quando disponível.

## Como consultar documentação local

Use `man nome_do_comando` para abrir a página de manual instalada. Para comandos que oferecem essa opção, `nome_do_comando --help` mostra um resumo de uso. Confirme a disponibilidade e as opções na sua distribuição antes de executar comandos administrativos ou destrutivos.

# 16. Atalhos de Teclado

Este README secundário reúne notas de consulta e encaminha para documentação mais detalhada. Os links internos usam caminhos relativos e funcionam no GitHub e em editores Markdown.

## Itens desta tabela

### 1. `!!`

- Descrição: Re-executa o último comando no Bash/Zsh
- Exemplo/observação: Repeat the last command

### 2. `exit`

- Descrição: —
- Exemplo/observação: Log out of the session

### 3. `Ctrl + C`

- Descrição: `Control + C`
- Exemplo/observação: Kill current process

### 4. `Ctrl + G`

- Descrição: `Control + G`
- Exemplo/observação: Exit command history

### 5. `Ctrl + K`

- Descrição: `Control + K`
- Exemplo/observação: Cut part of the line after the cursor

### 6. `Ctrl + O`

- Descrição: `Control + O`
- Exemplo/observação: Run the recalled command

### 7. `Ctrl + R`

- Descrição: `Control + R`
- Exemplo/observação: Recall last command

### 8. `Ctrl + U`

- Descrição: `Control + U`
- Exemplo/observação: Cut part of the line before the cursor

### 9. `Ctrl + W`

- Descrição: `Control + W`
- Exemplo/observação: Cut the word before the cursor

### 10. `Ctrl + Y`

- Descrição: `Control + Y`
- Exemplo/observação: Paste from clipboard

### 11. `Ctrl + Z`

- Descrição: `Control + Z`
- Exemplo/observação: Stop process (can be resumed)

### 12. `Ctrl + Alt + F7`

- Descrição: `Control + Alt + F7`
- Exemplo/observação: Switch to the first graphical terminal

### 13. `Ctrl + Alt + F10`

- Descrição: `Control + Alt + F10`
- Exemplo/observação: Switch to a virtual console

## Como consultar documentação local

Use `man nome_do_comando` para abrir a página de manual instalada. Para comandos que oferecem essa opção, `nome_do_comando --help` mostra um resumo de uso. Confirme a disponibilidade e as opções na sua distribuição antes de executar comandos administrativos ou destrutivos.

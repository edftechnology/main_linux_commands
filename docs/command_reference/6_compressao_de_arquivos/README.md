# 6. Compressão de Arquivos

Este README secundário reúne notas de consulta e encaminha para documentação mais detalhada. Os links internos usam caminhos relativos e funcionam no GitHub e em editores Markdown.

## Itens desta tabela

### 1. `gzip [file]`

- Expansão/origem: GNU zip
- Descrição: Criar um arquivo comprimido gz
- Em inglês: Create a gz compressed file
- Ajuda local: consulte `man comando` ou `comando --help` quando disponível.

### 2. `tar xf [file.tar]`

- Expansão/origem: tape archive
- Descrição: Extrair arquivo arquivado
- Em inglês: Extract archived file
- Ajuda local: consulte `man comando` ou `comando --help` quando disponível.

### 3. `zip`/`unzip`

- Expansão/origem: —
- Descrição: Empacotar e comprimir arquivos
- Em inglês: Package & compress files
- Ajuda local: consulte `man comando` ou `comando --help` quando disponível.

### 4. `tar cf [file.tar] [file]`

- Expansão/origem: tape archive
- Descrição: Criar um arquivo tar a partir de um arquivo
- Em inglês: Create a tar file from a file
- Ajuda local: consulte `man comando` ou `comando --help` quando disponível.

### 5. `tar czf [file.tar.gz]`

- Expansão/origem: tape archive
- Descrição: Criar um arquivo tar gzip
- Em inglês: Create a gzip tar file
- Ajuda local: consulte `man comando` ou `comando --help` quando disponível.

## Como consultar documentação local

Use `man nome_do_comando` para abrir a página de manual instalada. Para comandos que oferecem essa opção, `nome_do_comando --help` mostra um resumo de uso. Confirme a disponibilidade e as opções na sua distribuição antes de executar comandos administrativos ou destrutivos.
